## 第 2 周：核心链路

### 目标流程（必须跑通）
```
用户：浏览商品 → 加购 → 下单 → mock 支付 → 看到「待发货」
商家：看到订单 → 发货 → 用户看到「已发货」
平台：（可选）审核通过商品后 C 端可见
```

### 分工并行
| 负责人 | W2 重点 |
|--------|---------|
| 成员 A | 用户端：列表、详情、购物车、结算、订单 |
| 成员 B | 商家端：商品 CRUD、库存、订单列表、发货 |
| 组长 | 订单/支付 API、平台审核、联调 |

### 每日 15 分钟站会（异步也可）
- 昨天做了什么
- 今天做什么
- 是否阻塞（接口未定义、字段不一致）

### W2 结束标准
- [ ] 上述主流程本地 Demo 可演示
- [ ] 订单状态与 `DOMAIN_MODEL` 一致
- [ ] 无 blocking 级 bug
