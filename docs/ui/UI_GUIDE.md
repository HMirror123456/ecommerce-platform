# UI 设计规范

> 全组统一视觉与布局，保证多端「像一个产品」。实现前确认技术栈与组件库。

## 1. 设计原则

1. **C 端**：清晰、促销友好、路径短（3 步内到结算）
2. **B 端（商家/平台）**：效率优先、表格 + 筛选 + 批量操作
3. **一致性**：同一语义同一颜色（成功绿、警告橙、错误红）

## 3. 色彩系统

### 3.1 品牌色（C 端参考京东红，可微调避免完全一致）

| 用途 | 色值 | CSS 变量 |
|------|------|----------|
| 主色 Primary | `#E4393C` | `--color-primary` |
| 主色 Hover | `#C81623` | `--color-primary-hover` |
| 成功 Success | `#52C41A` | `--color-success` |
| 警告 Warning | `#FAAD14` | `--color-warning` |
| 错误 Error | `#FF4D4F` | `--color-error` |

### 3.2 中性色

| 用途 | 色值 |
|------|------|
| 标题 | `#333333` |

## 4. 字体与间距

| 项 | 规范 |
|----|------|
| 字体 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |

## 5. 布局规范

### 5.1 用户端（web-user）

```
┌─────────────────────────────────────────┐
│  Logo    搜索框              购物车 登录  │  ← 顶栏 64px
├─────────────────────────────────────────┤
│  类目导航（可选侧栏或顶部分类）            │
├─────────────────────────────────────────┤
│                                         │
│              主内容区                    │
│                                         │
├─────────────────────────────────────────┤
│  页脚（链接、版权）                       │
└─────────────────────────────────────────┘
```

**关键页面清单：**
- [ ] 首页
- [ ] 商品列表
- [ ] 商品详情（SKU 选择器）
- [ ] 购物车
- [ ] 结算页
- [ ] 订单列表 / 详情
- [ ] 登录 / 注册

### 5.2 商家 / 平台后台

```
┌──────┬──────────────────────────────────┐
│      │  顶栏：面包屑 | 用户菜单           │
│ 侧   ├──────────────────────────────────┤
│ 边   │                                  │
│ 栏   │  内容区（表格/表单/卡片）          │
│      │                                  │
└──────┴──────────────────────────────────┘
```

- 侧边栏宽度：200–220px，可折叠
- 列表页：筛选区 + 表格 + 分页，操作列固定右侧

## 6. 组件约定

| 场景 | 组件 | 说明 |
|------|------|------|
| 主操作 | Primary Button | 每屏最多 1 个主按钮 |
| 危险操作 | Popconfirm + 红色按钮 | 删除、下架等 |
| 空状态 | Empty | 配图 + 引导文案 |
| 加载 | Skeleton / Spin | 列表用骨架屏 |
| 价格 | 整数大号 + 小数小号 | ¥199.00 |
