## 3. 核心用户流程

### 3.1 C 端购物流程
```
首页 → 类目/列表 → 商详 → 加购 → 购物车 → 结算 → 支付 → 订单详情
```

### 3.2 商家履约流程
```
登录 → 商品管理 → 提交审核 → （平台通过）→ 订单列表 → 发货
```

### 3.3 平台审核流程
```
登录 → 审核队列 → 通过/驳回 → 商家收到结果
```

- 真实短信验证码
- 推荐算法、千人千面
- 完整仓储 WMS
- 高并发、分布式事务
