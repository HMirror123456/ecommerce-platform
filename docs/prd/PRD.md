## 1. 项目概述

### 1.1 背景

课程作业：复刻类京东 B2C 电商平台，3 人 3 周协作。考察重点是**业务逻辑理解深度**（状态机、权限边界、售后联动），而非功能数量。

### 1.2 目标用户

| 角色 | 说明 | 使用端 |
|------|------|--------|
| C 端用户 | 浏览、下单、售后 | 网页 |
| 商家 | 商品管理、订单发货、售后审核 | 商家后台 |
| 平台运营/客服 | 审核、仲裁、查单 | 管理后台 |

### 1.3 成功标准（3 周）

- [x] 用户：注册登录 → 浏览商品 → 加购 → 下单 → mock 支付
- [ ] 商家：登录 → 上架商品 → 处理订单 → 发货
- [ ] 平台：登录 → 商品审核 → （P1）售后仲裁
- [ ] 文档齐全，报告能讲清核心业务逻辑

## 3. 核心用户流程

### 3.1 C 端购物流程

```
首页 → 类目/列表 → 商详 → 加购 → 购物车 → 结算 → 支付 → 订单详情
```

### 3.2 商家履约流程

```
登录 → 商品管理 → 提交审核 → （平台通过）→ 订单列表 → 发货
```

### 3.3 售后流程（P1，报告重点）

```
用户申请 → 商家48h内审核 → （超时/申诉）→ 平台仲裁 → 退款完成
```
